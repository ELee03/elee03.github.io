# elee03.github.io

Personal website for Eugene Lee — Electrical Engineer, University of Toronto (2026).

Built with static HTML and CSS. No frameworks, no build step.

## Pages

- **About** (`index.html`) — background, tech stack, interests
- **Work & Projects** (`work/index.html`) — industry experience, research, academic work
- **Reading List** (`reading/index.html`) — books read, reading, and in queue

## Design

Retrofuturist aesthetic — Space Age typography meets broadsheet print layout. Warm cream background, deep navy text, ice blue ornamental accents. Fonts: DM Serif Display, Space Grotesk, Georgia.

## Structure

```
/
├── index.html          # About
├── style.css           # Shared stylesheet
├── work/
│   └── index.html      # Work & Projects
└── reading/
    └── index.html      # Reading List
```
